# Forgot Email Digits Tool

## Everyday Problem

When recovering legacy accounts or secondary profiles, services often mask your login as `user****@domain.com`. If you remember the handle prefix but not the trailing numbers, account recovery halts.

## The Solution

An exhaustive permutation generator designed for email recovery. By entering the remembered handle prefix, target domain, and missing digit count (1–5 digits), this utility automatically calculates all valid zero-padded number combinations and divides large sets into manageable 1,000-row batch files.

## Usage & Workflow

1. **Enter Known Prefix**: Input the remembered handle prefix (e.g., `fredrobinson`).
2. **Set Domain**: Select or type the email provider domain (e.g., `@gmail.com`).
3. **Specify Missing Digits**: Set how many numeric characters were appended (1 to 5 digits).
4. **Choose Format**: Pick between CSV and plain text (`.txt`).
5. **Generate & Download**: Click **Generate & Show Download Options** to produce paginated batch files ready for bulk account verification tools.

## Outcome

A structured, complete candidate list ready for automated verification without manual guessing.
