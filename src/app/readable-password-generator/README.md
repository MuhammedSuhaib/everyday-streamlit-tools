# Readable Password Generator

## Everyday Problem

Fully randomized passwords are secure but difficult to remember or type manually on mobile keyboards. Conversely, simple patterns get compromised quickly via dictionary attacks.

## The Solution

A mnemonic-driven password generator. It accepts an everyday memorable base phrase (e.g. `Streamlit experts.`) and introduces leetspeak transformations, casing variations, and symbol padding to satisfy password policies while remaining easy to remember.

## Usage & Workflow

1. **Input Base Phrase**: Type a memorable sentence or words (e.g., `Coffee is fuel`).
2. **Set Length Target**: Choose your desired minimum password length (default: 17 characters).
3. **Generate**: Click **Generate Password** to transform the phrase into a high-entropy string.
4. **Copy & Use**: Store or enter the generated password into your accounts.

## Outcome

Strong, complex passwords that satisfy security requirements without forcing constant password resets.
