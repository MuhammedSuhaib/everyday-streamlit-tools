# Phone Number Info

## Everyday Problem

Receiving international messages or customer inquiries often leaves you guessing where the caller originated, whether the line is VoIP/toll-free or mobile, and if the dialing format adheres to international standards.

## The Solution

A telephone number parsing and validation engine powered by `phonenumbers` metadata. Paste any international phone number with its country code to instantly parse region codes, geographic locations, carrier names, timezones, and normalized E.164 dial formats.

## Usage & Workflow

1. **Input Phone Number**: Type the phone number including its country code (e.g. `+14155552671` or `+628123456789`).
2. **Execute Lookup**: Click **Track** to parse and validate against telecommunication standards.
3. **Inspect Output**:
   - **Location & Region**: Identified country and state or province.
   - **Carrier & ISP**: Mobile network operator.
   - **Timezone**: Applicable timezone for timing outbound calls appropriately.
   - **Standard Formats**: Standard International and mobile dialing strings.
   - **Line Type**: Classified as Mobile, Fixed-line, VoIP, Toll-free, or UAN.

## Outcome

Instant clarity on unknown incoming numbers, preventing spam and ensuring properly formatted contacts for business messaging.
