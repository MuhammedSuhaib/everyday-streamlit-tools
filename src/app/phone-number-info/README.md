# GhostTrack

📱 Phone number tracker web app built with Streamlit.

## Credits

Original concept by **[HunxByts](https://github.com/HunxByts/GhostTrack)**

## Features

- 🌍 Location lookup
- 📡 Carrier/ISP detection
- ⏰ Timezone information
- ✅ Number validation
- 📞 Format conversion

## Installation

```bash
uv sync
```

## Usage

```bash
uv run streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`

## Screenshot

Enter a phone number with country code (e.g., `+628123456789`) to see:
- Location and region
- Carrier/provider name
- Timezone
- International and mobile formats
- Number type (mobile, fixed-line, etc.)
