# Streamlit Apps Suite

## Everyday Problem

Juggling multiple isolated utility scripts requires running separate commands, tracking disparate ports, and navigating between disjointed terminal windows.

## The Solution

A unified command center and landing page for all everyday tools. Provides direct visual cards with one-click app switches, status descriptions, and shared layout standards.

## Usage & Workflow

1. Start the main suite via `run.bat` or `uv run streamlit run main.py`.
2. Browse through the available utility cards on the dashboard grid.
3. Click **Launch App** on any card to immediately switch to that tool's interactive view.
4. Use the sidebar to toggle back to **Home** or between tools at any time.

## Outcome

A centralized dashboard providing instantaneous access to your entire daily utility belt.
